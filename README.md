# 日常選物：靜態商品網站

直接開啟 `dist/index.html` 即可使用，不需安裝套件。圖片需要網路。

包含六款示範商品、分類與搜尋、商品款式、購物袋、台灣宅配與 7-ELEVEN／全家取貨表單、免付款示範訂單與明細下載。手機與桌面皆可使用。

**這是靜態示範，不會傳送訂單給商家。** 購物袋及最後一筆示範訂單只儲存在目前瀏覽器。請勿填寫真實個資。超商門市手動填寫，未串接電子地圖。示範宅配運費 NT$100，超商 NT$60。

商品資料在 `dist/app.js` 的 `products` 陣列；名稱、價格、圖片、款式、說明與示範庫存可在此調整。整體配色與版面在 `dist/style.css`。正式營業前需替換真實商品資料、運費與退換貨政策，並串接訂單接收及儲存服務。
